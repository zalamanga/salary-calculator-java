# Asal sumber

Proyek ini berasal dari latihan lokal NetBeans **SalaryCalculator**, package `calculator`, dengan entry point `SalaryCalculator`.

Tarif asal dipertahankan: HRA sebesar 50% gaji pokok, special allowance 75%, dan pengurang PF 12%. Versi Maven mengganti aritmetika integer dengan `BigDecimal`, memisahkan hasil perhitungan, serta menambahkan validasi input dan pengujian.

Nama penulis dan lisensi sumber tidak ditemukan pada berkas asal yang tersedia. Repository ini tidak menetapkan lisensi baru atau mengklaim kepemilikan eksklusif atas sumber awal.
